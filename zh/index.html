MCP Kit快速生成 MCP 服务端与客户端

选择 TypeScript 或 JavaScript、STDIO 或 Streamable HTTP，从可运行的协议示例开始开发。

开始使用 👆
查看 GitHub
  • 🚀

    快速脚手架

    通过简短的引导式配置，生成可运行的 MCP 服务端或客户端。

  • 📦

    TypeScript 或 JavaScript

    两种语言都采用现代 ESM 模板，并提供开箱即用的 TypeScript 类型安全。

  • 🔗

    完整协议工作流

    内置可运行的知识库示例，端到端串联工具、资源与提示。

  • 🛠️️

    可选开发工具

    可加入 Vitest、GitHub Actions、MCP Inspector、代码检查、提交检查和变更日志。

  • 🔧️

    标准或自定义

    选择推荐配置，或仅启用适合当前工作流的插件。

  • 🌐️

    两种传输模式

    可生成 STDIO、Streamable HTTP 或同时生成两者，并配套对应源码与开发脚本。
