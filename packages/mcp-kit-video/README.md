# MCP Kit CLI launch video

A deterministic, 48-second Remotion walkthrough of the real `create-mcp-kit`
interactive flow.

## Commands

From the repository root:

```sh
pnpm --filter @mcp-kit/video preview
pnpm --filter @mcp-kit/video check
pnpm --filter @mcp-kit/video render
```

The composition is `McpKitCliWalkthrough` at 1920×1080, 30fps, and exactly
1440 frames.

## Audio

The background track is an edited 48-second highlight from **Digital Clouds**
by Alejandro Magaña (A. M.), downloaded from
[Mixkit](https://mixkit.co/free-stock-music/electronic/) under the
[Mixkit Stock Music Free License](https://mixkit.co/license/#musicFree).
The source segment is `00:27.8–01:15.8`, with short edge fades added for the
video edit.

The interface sound effects in `public/audio` are original procedural
syntheses generated by `scripts/generate-audio.mjs`. Regenerate the sound
effects with:

```sh
pnpm --filter @mcp-kit/video audio:generate
```

The terminal uses Remotion's `HtmlInCanvas` WebGL2 path when supported. A
frame-driven DOM fallback retains scanlines, grain, flicker, and vignette when
HTML-in-canvas is unavailable. Rendering is configured to use ANGLE.
